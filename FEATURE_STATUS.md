# Feature status

Honest state of GestureLink 3.0. This file is updated at the end of every
milestone. A feature is only listed under **Completed** when it has been run in
a browser; model accuracy that needs a real hand in front of a camera is never
claimed from a headless test.

Last updated: stage 5 (sign dictionary, history export).

## Not implemented

- Replay of the recorded landmark window in the reader's history. The export
  contains the committed readings with timestamps, confidence and reader mode,
  not raw landmark sequences.
- Two-handed sign recognition beyond the second hand's offset and presence: the
  second hand's own landmark shape is not part of the model.
- Per-label unknown thresholds. The reader uses one configurable threshold;
  distance distributions per label were not built.
- Migration of older single-frame samples. They remain in IndexedDB, are not
  converted, and are ignored (with a visible count) by a window model.
- Speech synthesis in languages the browser has no voice for, and any translation model. The caption language selector only chooses a voice language; no translation is bundled, and bilingual mode stays single-line without one.
- Keyboard shortcut overlay behind the top-bar help affordance.
- Route-level code splitting for the bundles listed above.

## Explicit non-goals for this build

- No pre-trained Indian Sign Language model is bundled. MediaPipe ships a
  seven-gesture generic recogniser, which is not a sign language model, so it is
  not used as one. Recognition runs on classes trained locally.
- No accuracy figure will be published without a measured evaluation on real
  recordings.

## Evaluated and rejected: public hand-shape dataset

The Kaggle dataset `aryarishabh/hand-gesture-recognition-dataset` (CC0) was
downloaded and trained on 2026-11-16 to see whether it can feed the sign reader.
It cannot, and nothing from it ships.

- Contents: 24,000 images, 20 classes, 50x50 grayscale binary hand silhouettes
  from an IR camera (900 train / 300 test per class). Labels are the numbers
  `0`-`19` only; the dataset documents no gesture or sign meaning.
- Measured: a 625-pixel -> 96-ReLU -> 20-softmax model trained in Node reached
  **99.87 % test accuracy (5,992 / 6,000)** after 20 epochs, with a 100 %
  validation slice. A nearest-centroid baseline that never iterates reaches
  98.40 %, and train/test share 0 identical images, so the score is real
  separability rather than leakage.
- Rejected because the silhouettes need background removal and cropping before
  a webcam frame can match them, the classes carry no sign-language labels, and
  the existing pipeline consumes MediaPipe's 21 landmarks (69 features), which
  50x50 silhouettes cannot provide. Class `0` also mixes two poses, so part of
  the score comes from the dataset's own label noise.
